# 2026-09-18 工作计划 / Plan

## 目标

回答一个提问：「检索 P@5 0.2（理论上限）？」——并把答案落地成代码。

结论是 P@5 在当前语料上**动不了**，而且这不是悲观是算术：每个查询只有 1 篇相关文档，
五取一就是天花板，检索已经贴着它。所以真正的问题不是「怎么让 P@5 变好」，
而是「为什么这套评测量不出检索质量」。

- 不把全链路评测放进 CI（runner 上两个模型都没有，会每次都拒，永远拒绝的检查等于没有检查）。
