## Executive Summary

QueryMind v0.7.0 marks a milestone release focusing on **interactive architectural observability**, **enhanced agent workflow visualization**, **execution trace introspection**, and **production-grade frontend performance optimizations**.

This release bridges the gap between deep backend agentic orchestration and intuitive frontend observability, allowing developers and enterprise administrators to inspect, trace, and understand multi-agent RAG decisions in real time across multiple dimensions.

---

## What's New in v0.7.0

### 1. Canonical LangGraph Architecture & Unified Orchestration (MAJOR)
- **Single Canonical Pipeline**: Replaced legacy multi-path procedural agents with a unified, stateful LangGraph engine (`app/orchestration/langgraph/workflow.py`).
- **Deterministic Scope Preflight**: Retrieval queries are bounded by the user's authenticated tenant scope before any search runs, preventing accidental cross-tenant data leaks.
- **Multimodal Evidence Ingestion**: Versioned document ingestion with streaming PDF parser, parent-child chunks (1500/600 token boundaries), Tesseract OCR fallback, and automatic chart/table extraction.
- **Unified Knowledge Orchestrator**: Integrated vector retrieval (ChromaDB + BGE-M3), lexical search (BM25 + jieba), and Reciprocal Rank Fusion (RRF) with dynamic BGE-Reranker-V2-M3.
- **Governed Planner & ReAct Tool Loop**: Complex queries trigger DAG task decomposition with strict per-stage budgets and circuit breakers.
- **Cross-Session Enterprise Memory**: Persistent memory governance allowing models to recall relevant user preferences across sessions.
- **Bounded Verification & DLP Guard**: Three-tier validation (citation-completeness, sentence grounding, and NLI entailment) plus boundary output redaction.

### 2. Deep Code Cleanup & SonarCloud Quality Hardening (QUALITY)
- **Cognitive Complexity Reduction (S3776)**: Refactored scores of high-complexity functions across routers, upload handlers, synthesizers, index managers, validators, and chat dispatchers down to strict cognitive complexity thresholds.
- **Async Event Loop Reliability**: Eliminated blocking I/O calls within async contexts, optimized regex scanning engines, and pruned dead async routines.
- **Synchronous Event Pipeline**: Streamlined execution event broadcasting to eliminate micro-delays in SSE token streaming.
- **Legacy Pruning**: Deleted 40+ legacy compatibility shims, orphaned agent wrappers, and deprecated test suites (-20,000+ lines of dead code).

### 3. Frontend Modernization & Tailwind CSS v4 Migration (UI/UX)
- **Tailwind CSS v4 Migration**: Replaced legacy scattered stylesheets with Tailwind v4 `@theme` design tokens and `tw-animate-css`.
- **Accessible Dialog Primitives**: Replaced native browser popups with Promise-based, fully accessible `ConfirmDialog` and `PromptDialog` components.
- **Zustand Architecture**: Granular state subscriptions eliminating unnecessary re-renders during active streaming responses.
- **Responsive Workspace**: Full 100vh viewport utilization, compact composer panel, dynamic document action chips, and streamlined markdown message cards.

### 4. Interactive Pipeline & Architecture Flow Visualization
- **Multi-Perspective Architecture Explorer**: Introduced `PipelineFlowDiagram` with five selectable viewing modes:
  - 📖 **Story Mode**: Narrative journey walking through the end-to-end user request lifecycle.
  - ⚙️ **Tech Mode**: Granular engineering view showing component contracts, timeouts, and state transitions.
  - 📊 **Table Mode**: Structured matrix breaking down stages, execution budgets, and fallback policies.
  - 🗺️ **Blueprint Mode**: High-resolution system flow diagram illustrating the hybrid multi-agent pipeline.
  - 🕸️ **Topology Mode**: Interactive topological graph driven by ReactFlow with live data pathways.
- **Scenario Simulation**: Instant switching between `RAG (Standard Retrieval)`, `ReAct (Tool-Governed Agent)`, and `Graph RAG (Knowledge Graph Multi-Hop)`.
- **System Metrics & KPIs**: Real-time visualization of router intent accuracy (>99%), grounding verification rate, and end-to-end latency benchmarks.

### 5. Deep Execution Trace Panel (`ExecutionTracePanel`)
- **Real-Time Step Tracing**: Comprehensive timeline visualizer for LangGraph execution events via SSE.
- **Hierarchical Trace Tree**: Formats nested tool invocations, retrieval stages, reasoning thoughts, and verifier rounds.
- **Per-Stage Telemetry**: Displays fine-grained timing, token budgets, circuit breaker states, and error recovery actions.
- **Developer Inspection**: Clean copying of raw trace events, payload inspection, and search filtering.

### 6. Landing Page & Feature Detail Modals
- **Interactive Feature Explorer**: Added `FeatureDetailModal` allowing users to inspect the implementation mechanics, source files, and engineering specifications of every core capability directly from the landing page.
- **Bilingual Consistency**: Full English and Chinese localization across all new architecture views and technical descriptions.

### 7. Performance & Production Build Optimizations
- **Production Preview Workflow**: Unified Vite preview server (`npm run preview`) with automated API reverse proxying to backend (`:8000`).
- **Gzip & Bundle Efficiency**:
  - Gzipped core bundle size reduced by **>91%** compared to unbundled development mode.
  - Sub-150ms DOM Ready and fast first-contentful paint across landing and console pages.
  - Clean modular chunks with lazy-loaded heavier route dependencies.
