## Executive Summary

QueryMind v0.7.0 marks a milestone release focusing on **interactive architectural observability**, **enhanced agent workflow visualization**, **execution trace introspection**, and **production-grade frontend performance optimizations**.

This release bridges the gap between deep backend agentic orchestration and intuitive frontend observability, allowing developers and enterprise administrators to inspect, trace, and understand multi-agent RAG decisions in real time across multiple dimensions.

---

## What's New in v0.7.0

### 1. Interactive Pipeline & Architecture Flow Visualization
- **Multi-Perspective Architecture Explorer**: Introduced `PipelineFlowDiagram` with five selectable viewing modes:
  - 📖 **Story Mode**: Narrative journey walking through the end-to-end user request lifecycle.
  - ⚙️ **Tech Mode**: Granular engineering view showing component contracts, timeouts, and state transitions.
  - 📊 **Table Mode**: Structured matrix breaking down stages, execution budgets, and fallback policies.
  - 🗺️ **Blueprint Mode**: High-resolution system flow diagram illustrating the hybrid multi-agent pipeline.
  - 🕸️ **Topology Mode**: Interactive topological graph driven by ReactFlow with live data pathways.
- **Scenario Simulation**: Instant switching between `RAG (Standard Retrieval)`, `ReAct (Tool-Governed Agent)`, and `Graph RAG (Knowledge Graph Multi-Hop)`.
- **System Metrics & KPIs**: Real-time visualization of router intent accuracy (>99%), grounding verification rate, and end-to-end latency benchmarks.

### 2. Deep Execution Trace Panel (`ExecutionTracePanel`)
- **Real-Time Step Tracing**: Comprehensive timeline visualizer for LangGraph execution events via SSE.
- **Hierarchical Trace Tree**: Formats nested tool invocations, retrieval stages, reasoning thoughts, and verifier rounds.
- **Per-Stage Telemetry**: Displays fine-grained timing, token budgets, circuit breaker states, and error recovery actions.
- **Developer Inspection**: Clean copying of raw trace events, payload inspection, and search filtering.

### 3. Landing Page & Feature Detail Modals
- **Interactive Feature Explorer**: Added `FeatureDetailModal` allowing users to inspect the implementation mechanics, source files, and engineering specifications of every core capability directly from the landing page.
- **Bilingual Consistency**: Full English and Chinese localization across all new architecture views and technical descriptions.

### 4. Performance & Production Build Optimizations
- **Production Preview Workflow**: Unified Vite preview server (`npm run preview`) with automated API reverse proxying to backend (`:8000`).
- **Gzip & Bundle Efficiency**:
  - Gzipped core bundle size reduced by **>91%** compared to unbundled development mode.
  - Sub-150ms DOM Ready and fast first-contentful paint across landing and console pages.
  - Clean modular chunks with lazy-loaded heavier route dependencies.
