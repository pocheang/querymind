# Release Notes - v0.7.0.3

**Release Date**: September 18, 2026  
**Type**: Feature / Quality & Standards  
**Scope**: Dynamic Dual-Track Clarification Agent, Codex/Claude Code Interaction Standards, Full SonarCloud Quality Gate Mastery, Comprehensive Regression Test Suite

## Overview

QueryMind v0.7.0.3 delivers a complete upgrade to the **Clarification Agent** subsystem, shifting from a purely static keyword-matching model to a production-grade **Dynamic Dual-Track Architecture**:
1. **Deterministic Fast-Path Rules**: Instantaneous zero-LLM extraction and completeness verification for well-defined queries (RAG design, document comparison, troubleshooting, setup, usage, optimization).
2. **Dynamic LLM Intelligent Clarification**: For underspecified or ambiguous queries falling outside static patterns, the agent dynamically invokes the underlying model runtime to generate focused, high-value clarifying questions rather than blindly guessing user intent.

Furthermore, all interactive clarification prompts and frontend interfaces have been standardized against **Codex / Claude Code** engineering guidelines, and the release achieves a **100% clean sheet across SonarQube / SonarCloud Quality Gate metrics (OK, 0 Bugs, 0 Vulnerabilities, 0 Code Smells)**.

---

## Key Highlights

### 1. Dynamic Dual-Track Clarification Architecture
- **Deterministic Boundary**: Queries matching well-known technical intents are evaluated with zero LLM latency and bounded cognitive complexity (`rules.py`).
- **Dynamic Reasoning Fallback**: Queries requiring nuanced domain clarifications invoke `ClarificationAgentService.clarify()` (sync and async), parsing structured JSON responses while ensuring deterministic fallback to continue execution when clarification is non-essential.
- **Model Runtime Integration**: Integrated with `app.services.models.runtime.get_chat_model()` to provide uniform invocation across cloud LLM providers (DeepSeek, OpenAI, Anthropic) and local Ollama instances.

### 2. Standardized Codex / Claude Code Questioning Patterns
- **Recommended Option First**: The optimal engineering choice is placed first and prefixed with `(推荐)` / `(Recommended)` along with explicit rationale and trade-off explanations.
- **Action-Oriented Declarative Choices**: Eliminated ambiguous single-word labels ("Option 1", "Plan A") in favor of informative, direct user-perspective statements.
- **Universal Custom Write-In Option**: Provided `"其他（自定义输入 / 补充说明）"` / `"Other (Custom input / specify details)"` as the terminal option, paired with frontend freeform input capabilities in `ClarificationPrompt.tsx`.
- **Bilingual Support**: Canonical clarification prompts and static templates are fully localized in both Chinese and English.

### 3. SonarCloud Quality Gate 100% Clean Sheet (Quality Gate OK)
- **Zero Bugs (`pythonbugs:S6466`)**: Guarded collection indexing in `_normalize_options` with direct branch flow control, eliminating static analyzer out-of-bounds warnings.
- **Zero ReDoS Risks (`python:S8786`, `python:S5869`, `python:S6353`)**:
  - Replaced catastrophic backtracking JSON extraction regex with linear `find("{")` and `rfind("}")` string slice boundaries.
  - Replaced trailing punctuation regex with native Python `str.rstrip()`.
  - Bounded scale and keyword regexes using `\b` and `re.ASCII`.
- **Zero Duplicated Literals (`python:S1192`)**: Extracted recurring fallback option strings into shared constants `_OTHER_OPTION_ZH` and `_OTHER_OPTION_EN`.
- **Clean Test Assertions (`python:S9073`)**: Decomposed composite assertions into distinct atomic statements.
